# 小卖部进货优化问题——深度建模分析

## 一、问题定性

**问题1**：属于**优化问题**中的**单变量可行性求解**（整数规划特例）。已知预算约束，求在预算限制下单独进货可乐的最大可行数量。

**问题2**：属于**线性整数规划（ILP）**中的**最大化利润**问题。两个决策变量（可乐、果汁进货量），受预算和货架容量双重约束，求最优进货组合。

---

## 二、数据洞察与预处理建议

原始数据：

| 饮料 | 进价(元) | 售价(元) | 库存上限(瓶) |
|------|---------|---------|------------|
| 可乐 | 2 | 5 | 60 |
| 果汁 | 4 | 8 | 60 |

**关键数据洞察**：

1. **利润差**：可乐每瓶利润 = 5 − 2 = 3元；果汁每瓶利润 = 8 − 4 = 4元。果汁单瓶利润更高。
2. **利润率差**：可乐利润率 = 3/2 = 150%；果汁利润率 = 4/4 = 100%。可乐**利润率**更高。
3. **进货量对预算的消耗**：1瓶可乐消耗预算2元，1瓶果汁消耗预算4元。
4. **货架容量**：两种饮料合计 ≤ 60瓶。
5. **单一商品最大进货**：各有存货上限60瓶。

**预处理建议**：
- 所有价格、数量均为整数，决策变量取整数（瓶数），建立整数规划模型。
- 无需处理缺失值或异常值，数据量极小且完整。

---

## 三、合理假设

1. **完全销售假设**：当日进的货当日全部售出，无库存积压。
2. **确定性需求**：市场需求充足，不设需求上限约束（除货架容量外）。
3. **线性关系**：成本、售价不随进货量变化（无批量折扣，无规模效应）。
4. **无其他成本**：不考虑运输、人工、损耗等其他费用。
5. **单日决策**：每天的进货决策独立，不考虑跨天联动。
6. **非负整数**：进货量为非负整数，且不超过每种饮料各自的库存上限60瓶。

---

## 四、数学模型构建

### 问题1建模

**决策变量**：
- $x_1$：可乐进货量（瓶）

**目标函数**：最大化进货量 $f = x_1$

**约束条件**：
- 预算约束：$2x_1 \leq 200$
- 库存上限：$x_1 \leq 60$
- 非负整数：$x_1 \geq 0$，$x_1 \in \mathbb{Z}$

**求解**：
$$x_1 \leq \min\left(\frac{200}{2},\ 60\right) = \min(100,\ 60) = 60$$

**结论**：问题1答案为 **60瓶**（受货架库存上限60瓶限制，而非预算——预算实际允许100瓶）。

---

### 问题2建模

**决策变量**：
- $x_1$：可乐进货量（瓶）
- $x_2$：果汁进货量（瓶）

**目标函数**（最大化总利润）：
$$\max Z = 3x_1 + 4x_2$$

其中：
- 3 = 5 − 2（可乐每瓶利润）
- 4 = 8 − 4（果汁每瓶利润）

**约束条件**：
1. 预算约束：$2x_1 + 4x_2 \leq 200$
2. 货架容量：$x_1 + x_2 \leq 60$
3. 各品库存上限：$0 \leq x_1 \leq 60$，$0 \leq x_2 \leq 60$
4. 整数约束：$x_1, x_2 \in \mathbb{Z}$

**代数化简**：
- 预算约束两边除以2：$x_1 + 2x_2 \leq 100$

**几何图示**：
可行域由两条约束线围成：
- 直线A（预算线）：$x_1 + 2x_2 = 100$，即 $x_1 = 100 - 2x_2$
- 直线B（货架线）：$x_1 + x_2 = 60$，即 $x_1 = 60 - x_2$

**交点**：
$$100 - 2x_2 = 60 - x_2 \Rightarrow x_2 = 40, \quad x_1 = 20$$

**目标函数斜率**：将目标写为 $x_2 = \frac{Z}{4} - \frac{3}{4}x_1$，斜率为 $-\frac{3}{4} = -0.75$。

**约束线斜率比较**：
- 预算线斜率：$-\frac{1}{2} = -0.5$
- 货架线斜率：$-1$

因为 $-0.75$ 介于 $-1$ 和 $-0.5$ 之间，目标函数等值线的法向量方向诱导最优点出现在**交点 (20, 40)** 处（需验证所有顶点）。

**验证所有可行顶点**：
- 顶点1：$(0, 0)$ → 利润 = 0
- 顶点2：$(60, 0)$ → 利润 = $3 \times 60 = 180$
- 顶点3：$(0, 50)$ → 利润 = $4 \times 50 = 200$（预算用满：$4 \times 50 = 200$）
- 顶点4：$(20, 40)$ → 利润 = $3 \times 20 + 4 \times 40 = 60 + 160 = \mathbf{220}$
- 顶点5：$(0, 0)$ 与 $(40, 0)$ 之间的非顶点... 补充验证：
  - 若仅进可乐（$x_2=0$）：$x_1 \leq 60$，利润 = $3 \times 60 = 180$
  - 若仅进果汁（$x_1=0$）：$x_2 \leq \min(50, 60) = 50$，利润 = $4 \times 50 = 200$
  - 若预算约束与货架约束同时紧：$(20, 40)$，利润 = **220** ← 全局最优

**最优解**：$x_1 = 20$（可乐），$x_2 = 40$（果汁），最大利润 = **220元**。

**实际约束检验**：
- 预算：$2 \times 20 + 4 \times 40 = 40 + 160 = 200 \leq 200$ ✓（预算刚好用满）
- 货架：$20 + 40 = 60 \leq 60$ ✓（货架刚好装满）
- 库存上限：$20 \leq 60$，$40 \leq 60$ ✓

两条约束同时恰好取等，最优解位于两条约束线的交点，是**非退化顶点解**。

## 五、求解算法推荐

### 问题1
- **直接解析法**：取 $\min\left(\lfloor 200/2 \rfloor, 60\right) = 60$，一步到位。

### 问题2
1. **图解法（推荐用于教学演示）**：绘制约束平面，沿目标函数梯度方向移动等值线，找到最远切点。适合二维小规模问题。
2. **单纯形法（Simplex）**：标准 LP 求解器（如 scipy.optimize.linprog），处理松弛变量与基可行解。适用于多维扩展。
3. **枚举法（整数穷举）**：因变量范围有限（$x_1, x_2 \in [0, 60]$），可用双重循环穷举，计算量约 3600 次组合，结果精确且不易出错。
4. **动态规划（背包类）**：若扩展为多种商品，可将问题视为带容量约束的多维背包问题，用 DP 求解。

**推荐实现**：用 Python 的 `scipy.optimize.linprog`（单纯形法）或 `pulp` 库（整数规划分支定界）求解，同时用图解法做结果交叉验证。

## 六、优劣势分析

### 问题1

| 方面 | 分析 |
|------|------|
| 优势 | 模型极简，约束单一，结果确定，无误差。 |
| 劣势 | 若忽略每商品库存上限，会误以为能进100瓶；实际答案受"60瓶"库存上限约束，说明**预算不是唯一瓶颈**，题目设陷阱考察约束筛选能力。 |

### 问题2

**模型优势**：
1. **线性性好**：目标函数和约束均为线性，全局最优解可通过顶点法精确获得，不存在局部最优陷阱。
2. **几何直观**：二维问题可用图解法可视化，计算结果易于验证。
3. **扩展性强**：从单店扩展到多店、多商品时，模型结构不变，仅增加维度和系数，可直接交给求解器。

**模型局限**：
1. **需求假设过强**：假设所有进货当日售罄，未考虑需求不确定性、滞销风险和陈列效应。
2. **线性假设简化**：现实中批发进货可能有阶梯折扣（进价随批量下降），模型一律按固定进价处理。
3. **未考虑时间维度**：饮料销售的季节性（夏季果汁需求高）、补货时点等均被忽略。
4. **整数规划解与线性松弛解可能不一致**：本题恰好整数解与LP松弛解一致，但大规模下可能出现小数解需取整，引入次优性。
5. **未考虑利润之外因素**：不反映现金流健康度（进可乐60瓶仅花120元/利润180元 vs 进20+40组合花200元/利润220元）、供应商关系、品类多样性等管理层面考量。

**深度洞察**：
问题2的有趣之处在于——**利润率更高的可乐（150%）并没有被优先选择**。原因是目标是最**总额利润**而非**利润率**。果汁虽单瓶利润多1元，且占用更多预算和货架，但通过"20瓶可乐+40瓶果汁"的组合，恰好同时用满预算（200元）和货架（60瓶），实现了两种资源的同时耗竭。这说明：**在多重约束下，最优解往往出现在约束的交点而非单一约束的端点**——这是线性规划的核心洞见。
